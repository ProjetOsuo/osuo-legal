# osuo-legal

Textes légaux publics de l'application Osuo, publiés avec GitHub Pages.

- `confidentialite/` : politique de confidentialité (lien demandé par Google Play et l'App Store).

Ce dépôt ne contient **que** ces textes : aucun code ni aucune donnée de l'appli.
L'adresse est configurable dans l'appli (`PRIVACY_POLICY_URL`) pour passer plus tard sur le domaine d'Osuo.
